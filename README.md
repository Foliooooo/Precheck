# PreCheck website

The site at [precheck.folioo.tech](https://precheck.folioo.tech). Next.js, exported as static files.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
```

`NEXT_PUBLIC_ANDROID_URL` sets where "Download for Android" points (defaults to the APK hosted at `/download/precheck.apk`).
